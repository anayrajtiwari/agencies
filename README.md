# SHRI Agencies (`shri-agency`)

> Strategic Growth, Deep SEO, & High-Voltage Web Craft for Category Leaders. Part of the Shri Hari Redirect Initiative (SHRI Division 03). Launching October 2026.

## Aesthetic DNA
- **Tactile Grain & Textures:** SVG noise overlay, dot-matrix backdrops, halftone accents.
- **Images in the Background:** Rich atmospheric visual compositions blended with dark gradients.
- **V0 Frontend Architecture:** Modular Next.js 15, React 19, Tailwind CSS, Lucide React, Framer Motion.
- **Interactive Tools:** Dynamic Scope Builder & Sprint Calculator, velocity marquee, Anti-Agency matrix, and application modal.

## Getting Started
```bash
npm run dev
# Starts local server at http://localhost:3000

npm run build
# Compiles production-ready static & SSR assets
```
